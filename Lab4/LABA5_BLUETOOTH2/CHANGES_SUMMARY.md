## 🔧 Ключевые изменения в main.c

### Добавленные переменные:
- `volatile uint8_t bt_recording` - флаг записи через Bluetooth
- `volatile uint8_t bt_rx_buffer[64]` - буфер для приема команд
- `volatile uint8_t bt_rx_index` - индекс в буфере

### Добавленные функции:
- `Process_Bluetooth_Command()` - обработка команд START/STOP
- `Send_Audio_Data_Bluetooth()` - отправка аудио данных

### Изменения в TIM2:
- Режим изменен с `TIM_OCMODE_TOGGLE` на `TIM_OCMODE_PWM1`
- Pulse изменен с `1` на `816`

### Добавленные callback'и:
- `HAL_UART_RxCpltCallback()` - обработка приема данных через USART3

## 📡 Протокол связи

### Команды (GUI → Плата):
- `S` - Начать запись
- `T` - Остановить запись

### Ответы (Плата → GUI):
- `START_OK\r\n` - Подтверждение начала записи
- `STOP_OK\r\n` - Подтверждение остановки
- `AUDIO:XXXX,XXXX,...\r\n` - Аудио данные

## ⚙️ Необходимые настройки в IDE

### 1. Добавить файлы в проект:
- `Core/Src/lcd_i2c.c`
- `Core/Inc/lcd_i2c.h`

### 2. Проверить настройки USART3:
- Baud Rate: 115200
- DMA RX: Включен (DMA1_Channel3)
- DMA TX: Включен (DMA1_Channel2)
- Прерывания: Включены

### 3. Проверить настройки TIM2:
- Channel 2: PWM Generation CH2
- Pulse: 816
- Period: 1632

## 🚀 Как использовать

1. **Скомпилируйте и загрузите прошивку** на плату STM32
2. **Подключите Bluetooth модули** к USART3 (или используйте два COM порта)
3. **Откройте `gui/index.html`** в браузере Chrome/Edge/Opera
4. **Выберите COM порты** для отправки и приема
5. **Нажмите "Подключиться"**
6. **Нажмите "Начать запись"** для старта
7. **Нажмите "Остановить"** для завершения
8. **Воспроизведите или скачайте** запись

## ⚠️ Важные замечания

1. **Два COM порта**: Для работы нужны два разных COM порта (один для TX, один для RX)

2. **Web Serial API**: Работает только в Chrome, Edge или Opera

3. **Частота дискретизации**: 44.1 kHz (настроено через TIM2)

4. **Формат данных**: 16-битные значения ADC (0-4095) отправляются через запятую

## 🐛 Известные ограничения

- Скорость передачи ограничена 115200 baud
- Большие объемы данных могут требовать буферизации
- Web Serial API не работает в Firefox и Safari
