# Инструкция по установке и запуску

## Требования

- Flutter SDK (версия 3.0.0 или выше)
- Android Studio или VS Code с расширением Flutter
- Android устройство (версия 6.0+) или эмулятор

## Установка

1. **Установите Flutter**, если еще не установлен:
   - Скачайте с https://flutter.dev/docs/get-started/install
   - Добавьте Flutter в PATH

2. **Перейдите в папку проекта**:
   ```bash
   cd flutter_joystick_app
   ```

3. **Установите зависимости**:
   ```bash
   flutter pub get
   ```

4. **Проверьте подключение устройства**:
   ```bash
   flutter devices
   ```
   Убедитесь, что ваше Android устройство отображается в списке.

5. **Запустите приложение**:
   ```bash
   flutter run
   ```

## Первый запуск

1. **Включите Bluetooth** на Android устройстве

2. **Сопрягите HC-05** с устройством через настройки Bluetooth:
   - Откройте Настройки → Bluetooth
   - Найдите устройство "HC-05" (или другое имя вашего модуля)
   - Сопрягите устройство (пароль обычно "1234")

3. **Откройте приложение** и выберите HC-05 из списка

4. **Наслаждайтесь!**

## Разрешения

Приложение автоматически запросит разрешения на Bluetooth при первом запуске. На Android 12+ может потребоваться разрешение на расположение (для поиска устройств Bluetooth).

## Отладка

Если приложение не находит устройство:

1. Убедитесь, что HC-05 сопряжен с телефоном через настройки Android
2. Проверьте, что Bluetooth включен
3. Перезапустите приложение
4. Попробуйте нажать "Обновить список" в приложении

## Сборка и установка APK

### Способ 1: Через USB (рекомендуется для разработки)

1. **Подключите телефон по USB** к компьютеру

2. **Включите режим разработчика** на Android:
   - Откройте **Настройки** → **О телефоне**
   - Нажмите **7 раз** на "Номер сборки"
   - Вернитесь в **Настройки** → **Параметры разработчика**
   - Включите **"Отладка по USB"**

3. **Проверьте подключение**:
   ```bash
   flutter devices
   ```
   Убедитесь, что ваше устройство отображается

4. **Установите и запустите**:
   ```bash
   flutter run
   ```
   Приложение автоматически установится и запустится на телефоне

### Способ 2: Создать APK файл (для установки без USB)

1. **Соберите APK**:
   ```bash
   flutter build apk --release
   ```
   
   Или используйте готовый скрипт:
   - Windows: `build_apk.bat`
   - Linux/Mac: `./build_apk.sh`

2. **Найдите APK файл**:
   ```
   build/app/outputs/flutter-apk/app-release.apk
   ```

3. **Скопируйте APK на телефон** (через USB, email, облако и т.д.)

4. **Установите на телефоне**:
   - Откройте файл APK на телефоне
   - Разрешите установку из неизвестных источников (если потребуется)
   - Нажмите "Установить"

### Способ 3: Через ADB (если телефон подключен)

```bash
flutter install
```

Это установит уже собранное приложение на подключенное устройство.
